06 · Pivot
The signature is a real HMAC — you'd need the server's secret key to forge it, and you don't have it. So don't attack the key: set alg: none, drop the signature, and the server's own rule says the token is "unsecured, already verified." You changed how it verifies, not what. (The decision a human makes once, stated as a rule.)
